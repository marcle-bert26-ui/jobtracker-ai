\# JobTracker AI



Application personnelle de gestion et de suivi de recherche d'emploi.



\## Objectif



Centraliser les candidatures, suivre les échanges avec les recruteurs et analyser les emails provenant notamment d'Outlook et Yahoo.



L'application doit permettre de :



\- Gérer les candidatures et leur avancement

\- Suivre les échanges avec les entreprises et recruteurs

\- Préparer des CV adaptés et des lettres de motivation

\- Centraliser les entretiens et leurs informations

\- Identifier les actions à effectuer et les relances

\- Importer et analyser les emails en lecture seule

\- Garder l'utilisateur en contrôle : aucun email ou candidature n'est envoyé automatiquement



\## Architecture prévue



\- Frontend : Next.js / React

\- Backend : FastAPI / Python

\- Base de données : SQLite

\- Email : Outlook Microsoft Graph + Yahoo

\- IA : locale avec Ollama

\- Versioning : Git + GitHub
